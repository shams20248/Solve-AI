# Solve AI

منصة ذكية متكاملة لإدارة الشركات والعمليات المالية، مصممة للعمل في بيئات المؤسسات والشركات وتدعم نموذج الاشتراك.

## المميزات الرئيسية

- لوحة تحكم عربية متجاوبة للحاسوب والهاتف
- نظام تسجيل دخول تجريبي مع حساب مدير
- إدارة مالية ومؤشرات أداء
- تحليل ذكي للإيرادات والمصروفات
- نظام اشتراكات متعدد المستويات (Starter / Professional / Enterprise)
- واجهات احترافية مناسبة للشركات

## بيانات الدخول التجريبية

- البريد الإلكتروني: `admin@solveai.com`
- كلمة المرور: `admin123`

## التشغيل محلياً

```bash
npm install
npm run dev
```

## الخطة المستقبلية

- إضافة قاعدة بيانات حقيقية
- ربط API للتسجيل والدخول
- نظام الدفع والسحب البنكي
- إدارة شركات متعددة
- تقارير ذكية جدًا
- واجهة إدارة للأدوار والصلاحيات
